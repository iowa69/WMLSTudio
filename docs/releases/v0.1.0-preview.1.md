# WMLSTudio 0.1.0 — first portable preview

Download **WMLSTudio-Windows-x64.zip**, extract the whole archive, open the
`WMLSTudio` folder and double-click **WMLSTudio.exe**. Start with **Practice project**
to explore seven synthetic assemblies without preparing data.

No separate Python installation, WSL, browser or administrator privileges are
required by the application. Keep `_internal` beside the executables. This is an
unsigned development preview targeting Windows 11 x64, not a production release.

## Included

- Native animated Qt interface, saved projects and cancellable analysis.
- Exact assembly typing with 162 staged reference schemes and custom scheme import.
- FASTA/FASTQ quality checks, shared-locus comparisons and an interactive graph.
- PDF/HTML reports, CSV/TSV/JSON exports and provenance hashes.
- HYDRA JSON report import and evidence display; HYDRA execution is not included.
- Python, Qt, the compiled matching engine and a command-line companion.

## Validation and limits

The supplied ZIP is the Windows Python 3.12.10 / Qt 6.11.2 build exercised under
Wine 11.17 on Linux. Its frozen GUI and CLI passed smoke checks; real assembly
typing also passed after extracting into a path with spaces and non-ASCII
characters. The source suite passed 198 tests on Linux and 198 under Windows
Python/Qt through Wine. Four local assemblies agreed with existing WMLST results.

Separately, [the initial GitHub Actions run](https://github.com/iowa69/WMLSTudio/actions/runs/34705226772)
passed tests and frozen builds on Linux and Windows. This release asset is the
previously verified local ZIP, not a replacement downloaded from CI.

Clean Windows 11 desktop acceptance is still pending. Read assembly, novel-allele
inference, HYDRA engine execution and SeqSphere+ parity are not implemented or
established. This is not clinical or diagnostic validation.

The repository and release remain private. Reference-data and dependency notices
are retained in the ZIP. Before public redistribution, complete the snapshot-specific
rights review described in
[the third-party notices](https://github.com/iowa69/WMLSTudio/blob/v0.1.0-preview.1/studio_packaging/THIRD_PARTY_NOTICES.md).
