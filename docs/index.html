Would you rather have a Start-menu entry? Get the Windows installer instead.
Windows will say it protected your PC. That is normal. WMLST is not signed with a paid certificate, so the first time you run it Windows shows a blue box. Click More info, then Run anyway. Do not switch SmartScreen or Defender off.

Three steps

  1. Unzip the file you just downloaded, anywhere you like — Desktop, Documents, a USB stick.
  2. Open the folder and double-click WMLST.exe.
  3. Drag a FASTA file of assembled contigs onto the window. The sequence type appears in a few seconds.

Good to know

  • Windows 10 and 11, 64-bit. Nothing is written outside the folder you unzipped.
  • The allele database and the BLAST+ binaries are inside the zip, so it works offline.
  • Accepts FASTA, GenBank, EMBL and GFF, plain or gzipped.
  • Results are byte-identical to tseemann/mlst on the reference fixtures.
  • Research use only. Not a medical device.
