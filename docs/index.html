Download WMLST for Windows (portable)

the latest release·ZIP archive·published on GitHub

Would you rather have a Start-menu entry? Get the Windows installer instead. New installers are paused, so this opens the most recent release that has one.
Windows will say it protected your PC. That is normal. WMLST is not signed with a paid certificate, so the first time you run it Windows shows a blue box. Click More info, then Run anyway. Do not switch SmartScreen or Defender off.

Three steps

  1. Unzip it anywhere — Desktop, Documents, a USB stick. (Right-click → Extract All.)
  2. Double-click WMLST.exe inside that folder. Nothing to install.
  3. Drag your FASTA onto the window. Typing starts by itself; the sequence type appears in seconds.

Good to know

  • Windows 10 and 11, 64-bit. Nothing is written outside the folder you unzipped.
  • Everything is inside the zip — it works with no internet connection.
  • Accepts FASTA, GenBank, EMBL and GFF, plain or gzipped.
  • Research use only. Not a medical device.
